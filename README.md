# A list of awesome projects for ATS Mini

**Maintainers wanted:** This project is looking for maintainers to help keep the list accurate and up to date. If you’re interested, please open an issue.

## Firmware

- [ATS Mini Chinese Firmware (Adam1315138)](https://github.com/Adam1315138/ats-mini-zh) - Adds Simplified Chinese menus, remapped button gestures, station-seeking controls and scrolling station names. Includes RDS station-name handling and display-layout fixes, tested on Sunnygold N16R8 hardware. <img src="https://img.shields.io/badge/updated-2026--11--04-green" alt="Updated 2026-11-04" height="16">
- [ATS Mini Airband (AnTruongTV)](https://github.com/AnTruongTV/ats-mini-airband) - Adapts ATS Mini firmware for aviation-band reception through an external AIR-to-AM downconverter. Requires the additional converter hardware. <img src="https://img.shields.io/badge/updated-2026--09--04-green" alt="Updated 2026-09-04" height="16">
- [ATS Mini with GalGame (B5-Software)](https://github.com/B5-Software/ats-mini-with-galgame) - Adds interactive AI-generated stories and optional images while retaining the radio functions. Requires 16 MB flash, internet access and user-configured AI endpoints and credentials. <img src="https://img.shields.io/badge/updated-2026--11--06-green" alt="Updated 2026-11-06" height="16">
- [ATS Mini (barchiesi)](https://github.com/barchiesi/ats-mini) - Expands browser-based radio control, station-memory editing and configuration management. Includes configuration import/export and a documented JSON API. <img src="https://img.shields.io/badge/updated-2025--08--22-blue" alt="Updated 2025-08-22" height="16">
- [AirTime (cdburgess75)](https://github.com/cdburgess75/AirTime) - Cross-checks FM RDS and WWV timing and serves NTP over Wi-Fi for off-grid FT8/JS8 operation. WWV reception requires an audio connection to GPIO11; full WWV timecode decoding remains experimental. <img src="https://img.shields.io/badge/updated-2026--09--15-green" alt="Updated 2026-09-15" height="16">
- [ATS Mini Extended Edition (eldontyrellcorp)](https://github.com/eldontyrellcorp/ats-mini-extended-edition/) - Advertises FT8/FT4, CW, RTTY, PSK31, SSTV and weather-fax decoding, propagation estimates, weather and multilingual menus. Releases contain binaries only; decoding requires receiver audio on GPIO11 (V4A/V4B) or an INMP441 I2S microphone. <img src="https://img.shields.io/badge/closed%20source-yellow" alt="Closed source" height="16"> <img src="https://img.shields.io/badge/updated-2026--11--10-green" alt="Updated 2026-11-10" height="16">
- [RESONIK (ep3mhb)](https://github.com/ep3mhb/resonik-ats-mini) - Adds FT8/FT4 and CW decoding, automatic regional band plans, band and memory scanning, beacon tracking, propagation data, USB CAT control and CSV signal logging. Decoders require receiver audio on GPIO11 (V4B boards) and pause Wi-Fi while active. <img src="https://img.shields.io/badge/updated-2026--11--13-green" alt="Updated 2026-11-13" height="16">
- [ATS Mini (epiHATR)](https://github.com/epiHATR/ats-mini) - Adds on-device FT8 decoding and an audio waterfall to the ATS Mini firmware. Requires radio audio connected to GPIO11, already provided on V4a/V4b boards; older boards need a hardware modification. <img src="https://img.shields.io/badge/updated-2026--10--23-green" alt="Updated 2026-10-23" height="16">
- [ATS Mini (esp32-si4732)](https://github.com/esp32-si4732/ats-mini) - AM/FM/SSB firmware with RDS, EiBi shortwave schedules, band scanning, station memories and configurable display layouts and themes. Includes web-based configuration, Wi-Fi firmware updates and remote control over USB, Wi-Fi and Bluetooth LE. <img src="https://img.shields.io/badge/updated-2026--11--10-green" alt="Updated 2026-11-10" height="16">
- [ATS Nano (esp32-si4732)](https://github.com/esp32-si4732/ats-nano) - Minimal firmware intended as a starting point for developing your own ATS Mini software. Includes a browser-based parameter configurator and source variants with detailed English and Russian comments. <img src="https://img.shields.io/badge/updated-2025--08--15-blue" alt="Updated 2025-08-15" height="16">
- [ATS Mini (F4DHY)](https://github.com/F4DHY/ats-mini) - Adds a revised battery gauge, HF/CB band information and an optional fisheye tuning scale with frequency markers. Tested on V4 OSPI hardware; the fisheye layout remains a work in progress. <img src="https://img.shields.io/badge/updated-2026--09--02-green" alt="Updated 2026-09-02" height="16">
- [ATS Mini PU2QTF (fernandofatech)](https://github.com/fernandofatech/ats-mini-pu2qtf) - Adds an animated Morse-code startup screen, live NCDXF/IARU beacon identification and station presets for São Paulo and amateur bands. Includes a macOS/Linux USB tool for tuning, scanning, memories, screenshots and EiBi diagnostics. <img src="https://img.shields.io/badge/updated-2026--10--26-green" alt="Updated 2026-10-26" height="16">
- [ATS Neo (fsaev)](https://github.com/fsaev/ats-mini/tree/cmake_port) - Ports ATS Mini firmware to ESP-IDF, with receiver, display, networking and Bluetooth components. Available on the `cmake_port` development branch as an alternative firmware development foundation. <img src="https://img.shields.io/badge/updated-2026--10--15-green" alt="Updated 2026-10-15" height="16">
- [ATS Mini (G8PTN)](https://github.com/G8PTN/ATS_MINI) - Reworks the controls and S-meter, with smoother SSB tuning and per-band calibration and reception settings. Includes adjustable backlight brightness, battery-voltage display and serial remote control. <img src="https://img.shields.io/badge/updated-2025--03--31-blue" alt="Updated 2025-03-31" height="16">
- [DualBoot Firmware Manager (GNBD)](https://github.com/GNBD/ats-mini-dualboot) - Lets you select between two firmware slots, with separate settings, firmware updates, recovery tools and a web interface. Requires an ESP32-S3 with 16 MB flash and 8 MB PSRAM. <img src="https://img.shields.io/badge/updated-2026--11--04-green" alt="Updated 2026-11-04" height="16">
- [GNBD miniradio (GNBD)](https://github.com/GNBD/miniradio) - AM/FM/SSB firmware with RDS, band scanning, EiBi schedules, weather, web control and a theme editor with Lua scripting. Experimental; targets ESP32-S3 hardware with 16 MB flash, 8 MB PSRAM and the ATS Mini dual-boot layout. <img src="https://img.shields.io/badge/updated-2026--11--06-green" alt="Updated 2026-11-06" height="16">
- [Pocket SI4735 Dual Core Decoder (hjberndt)](http://www.hjberndt.de/dvb/pocketSI4735DualCoreDecoder.html) - Focuses on shortwave listening, with CW/RTTY, SSTV and weather-fax decoding, signal/waterfall displays and EiBi station information. Decoder features require the documented audio wiring or I2S microphone modifications. <img src="https://img.shields.io/badge/closed%20source-yellow" alt="Closed source" height="16"> <img src="https://img.shields.io/badge/updated-2026--10--26-green" alt="Updated 2026-10-26" height="16">
- [ATS Mini Monster (Ho52198)](https://github.com/Ho52198/ats-mini-monster) - Adds a redesigned web control panel, spectrum scanning with peak detection and CSV export, and saved per-band scans. Expands station memory to 200 named slots with favourites and CSV import/export, plus additional encoder and serial controls. <img src="https://img.shields.io/badge/updated-2025--12--26-blue" alt="Updated 2025-12-26" height="16">
- [my4732radio (ieomkg)](http://ieomkg.myds.me:20001/p/my4732radio) - FM, AM and SSB reception alongside Wi-Fi internet radio, with station favourites and spectrum displays. Includes weather forecasts, a calendar, clock faces, alarms and over-the-air updates. <img src="https://img.shields.io/badge/closed%20source-yellow" alt="Closed source" height="16"> <img src="https://img.shields.io/badge/updated-2026--11--09-green" alt="Updated 2026-11-09" height="16">
- [ATS Mini WebSDR (ivanessb)](https://github.com/ivanessb/ATS-MINI-websdr) - Streams the Maasbree WebSDR receiver over Wi-Fi and adds on-device network setup and smoother tuning steps. WebSDR audio requires PWM audio wiring and a low-pass filter on many ATS Mini boards. <img src="https://img.shields.io/badge/updated-2026--04--11-blue" alt="Updated 2026-04-11" height="16">
- [Arcade games (Jean Ayme)](https://drive.google.com/drive/mobile/folders/18l7T4wFrIzkrN22AacYUbXucMJduGRfg) - A collection of 30 mini-games for the ATS Mini, with versions in ten languages. Runs as standalone firmware or alongside radio firmware through Diamond Dual Boot on 16 MB devices.
- [ATS Mini KR UI (jh78bb)](https://github.com/jh78bb/ats-mini-kr-ui) - Adds Korean menus and FM station names, regional station identification, ATS/ETM scanning and saved-frequency backup. The Korean interface is tested on V4 OSPI hardware; QSPI and LILYGO builds are provided but untested on hardware. <img src="https://img.shields.io/badge/updated-2026--11--06-green" alt="Updated 2026-11-06" height="16">
- [ATS-Mini Remote Firmware (KD8QED)](https://atsmini.com/) - Adds a mobile-friendly web remote interface with real-time controls and themes inspired by classic HF transceivers. Requires an ESP32-S3 receiver with 16 MB flash. <img src="https://img.shields.io/badge/paid-orange" alt="Paid" height="16"> <img src="https://img.shields.io/badge/updated-2025--09--22-blue" alt="Updated 2025-09-22" height="16">
- [Diamond Radio (khanfar)](https://github.com/khanfar/diamond-radio-ats-mini) - Includes FT8/FT4, CW, RTTY and PSK31 decoding, SSTV and weather-fax reception, and a live audio waterfall. Supports station maps, weather information and firmware updates through Diamond Dual Boot. <img src="https://img.shields.io/badge/closed%20source-yellow" alt="Closed source" height="16"> <img src="https://img.shields.io/badge/updated-2026--11--09-green" alt="Updated 2026-11-09" height="16">
- [ATS Mini Kizito (kizomanizo)](https://github.com/kizomanizo/ats-mini-kizito) - Adds optional dot-matrix fonts, a drum-style tuning scale, station markers and a ballistic S-meter. Includes three mini-games that can run while the radio keeps playing. <img src="https://img.shields.io/badge/updated-2026--10--27-green" alt="Updated 2026-10-27" height="16">
- [tinyradio (lsongdev)](https://github.com/lsongdev/tinyradio) - AM/FM/SSB firmware with continuous tuning, station seeking, adjustable reception settings and dark/light themes. Supports RDS, UTF-8 extended radio text, saved settings and screenshot export. <img src="https://img.shields.io/badge/updated-2026--11--06-green" alt="Updated 2026-11-06" height="16">
- [ATS Mini CN (openwrt-1983)](https://github.com/openwrt-1983/ats-mini-cn) - Provides Simplified Chinese device and web interfaces, BLE standby and timed standby. Adds selectable encoder behaviour and numeric signal-strength readings. <img src="https://img.shields.io/badge/updated-2026--11--10-green" alt="Updated 2026-11-10" height="16">
- [phys1cs.com RADIO (phys1csgamez)](https://github.com/phys1csgamez/phys1cs-radio) - Provides a seven-marker interface, station memories, RF scanning and radio-learning tools. The ATS Mini port is experimental, with live audio decoding not yet implemented. <img src="https://img.shields.io/badge/updated-2026--10--26-green" alt="Updated 2026-10-26" height="16">
- [ATS Mini (PV2KSM)](https://github.com/PV2KSM/ats-mini-pv2ksm) - Adds analog, cockpit and avionics display layouts, plus internet-based flight tracking, weather, METAR reports and currency prices. Includes a live view of the radio screen in the web interface. <img src="https://img.shields.io/badge/updated-2026--11--08-green" alt="Updated 2026-11-08" height="16">
- [ATS-Mini Pro (sirruf)](https://github.com/sirruf/ats-mini-pro) - Replaces the display interface with LVGL, adding themes and a spectrum/waterfall bandscope. Provides a built-in web control panel, an HTTP API and an MCP server for control through AI agents. <img src="https://img.shields.io/badge/updated-2026--07--06-blue" alt="Updated 2026-07-06" height="16">
- [Original ATS Mini firmware (Sunnygold)](https://github.com/esp32-si4732/esp32-si4732-oshwhub) - Archive of the original receiver firmware source code and schematics published on OSHWHub. A newer version of the Chinese firmware is available as 4732mini by zhang-chong. <img src="https://img.shields.io/badge/updated-2025--04--03-blue" alt="Updated 2025-04-03" height="16">
- [ATS Mini (superogira)](https://github.com/superogira/ats-mini) - Adds browser controls for frequency, bandwidth, BFO and volume, plus signal charts and an embedded Icecast audio player. Browser audio playback requires an external streaming server. <img src="https://img.shields.io/badge/updated-2025--04--15-blue" alt="Updated 2025-04-15" height="16">
- [ESP32-SI4732 Radio (sureshmagnolia)](https://github.com/sureshmagnolia/ESP32-SI4732-Radio) - Combines AM/FM/SSB reception with internet-radio streaming and browser-managed station favourites. Internet-radio audio requires an added I2S audio module or the documented filtered PDM output circuit. <img src="https://img.shields.io/badge/updated-2026--09--13-green" alt="Updated 2026-09-13" height="16">
- [ATS Mini Salmer (wsalmi)](https://github.com/wsalmi/ats-mini-salmer) - Adds browser spectrum/waterfall controls, an offline USB-control web app and serial/HTTP APIs. Includes an on-device RSSI waterfall and CW decoding; web spectrum sweeps mute reception while scanning. <img src="https://img.shields.io/badge/updated-2026--06--14-blue" alt="Updated 2026-06-14" height="16">
- [ats_adv (zeromem0)](https://github.com/zeromem0/ats_adv) - Provides an application launcher with basic FM reception, RDS station names, serial inspection tools and a network clock. Includes browser screen mirroring and remote control, targeting ATS Mini V1 hardware. <img src="https://img.shields.io/badge/updated-2026--08--02-green" alt="Updated 2026-08-02" height="16">
- [4732mini (zhang-chong)](https://github.com/zhang-chong/4732mini) - AM/FM/SSB firmware with a graphical tuning scale, FM RDS station names, station memories and automatic seeking. Includes adjustable bandwidth, gain, soft mute, brightness and display sleep. <img src="https://img.shields.io/badge/updated-2026--03--07-blue" alt="Updated 2026-03-07" height="16">
